       - Para **JavaScript**:
         - Substituir `inputData.([a-zA-Z0-9_]+)` por `$input.first().json.$1`.

         - Adicionar cabeçalho comentado explicando o mapeamento `inputData -> $input.first().json`.
       - Para **Python**:
         - Substituir `input_data['([^']+)']` por `_input.first().json['$1']`.
         - Garantir retorno compatível com o nó Python nativo do n8n (`return [{'json': output}]`).
    2. `refineCodeWithAi(sourceCode: string, language: 'javascript' | 'python', settings: AiCopilotSettings): Promise<{ ok: boolean; code: string; providerUsed: string; error?: string }>`:
