<task type="auto">
  <name>Task 2: Implementar o Gerador de Grafo DAG n8n e Sticky Notes (n8nGenerator.ts)</name>
  <files>
    05-zapier-to-n8n/src/services/n8nGenerator.ts
  </files>
  <action>
    Criar `05-zapier-to-n8n/src/services/n8nGenerator.ts` implementando `convertZapToN8n(zap: NormalizedZap, affiliateConfig: AffiliateConfig): ConvertedZapItem`:
    1. **Deduplicação de Nomes de Nós:**
       - O n8n exige que cada nó tenha um `name` único no workflow. Se um Zap tiver dois passos do Slack, nomear como `"Slack - Send Message"` e `"Slack - Send Message 2"`.
       - Popular o `stepLookup` associando `step.id`, `String(step.index + 1)` e `step_${step.index + 1}` ao `name` único gerado.
    2. **Posicionamento Geométrico Automático (`[x, y]`):**
       - Fluxo linear principal: `baseX = 260`, `baseY = 340`, incrementando `x += 280` a cada passo.
       - Quando encontrar um nó `paths` (`n8n-nodes-base.switch` ou múltiplos `n8n-nodes-base.if`): distribuir as ramificações verticalmente (`branchY = baseY + (branchIndex - (totalBranches - 1) / 2) * 220`) e conectar a saída `main[branchIndex]` do nó `Switch` ao primeiro nó de cada ramificação!
    3. **Tradução Especializada de Utilitários do Zapier:**
       - `Filter by Zapier` $\rightarrow$ `n8n-nodes-base.if` (typeVersion `2`) com `conditions` populadas a partir de `step.filterConditions`.
       - `Paths by Zapier` $\rightarrow$ `n8n-nodes-base.switch` (typeVersion `3`) roteando cada branch para sua trilha de nós.
       - `Delay by Zapier` $\rightarrow$ `n8n-nodes-base.wait` (typeVersion `1.1`) com `amount` e `unit` (`minutes`, `hours`, `days`).
       - `Formatter by Zapier` $\rightarrow$ `n8n-nodes-base.dateTime` (quando ação for data) ou `n8n-nodes-base.set` (`Edit Fields`, typeVersion `3.4`).
       - `Code by Zapier` $\rightarrow$ `n8n-nodes-base.code` (typeVersion `2`) convertendo automaticamente referências `inputData.campo` para `$input.first().json.campo` e envolvendo o retorno em `return [{ json: output }];`.
       - **Fallback HTTP Request:** Se `appKey` não estiver em `NODE_MAPPINGS`, gerar `n8n-nodes-base.httpRequest` (typeVersion `4.2`), `mappingStatus: 'http_fallback'`, `confidenceScore: 65`, preservando todos os parâmetros transpilados no `bodyParameters` e adicionando nota no próprio nó (`notesInFlow: true`).
    4. **Geração da Sticky Note de Documentação (`n8n-nodes-base.stickyNote`):**
       - Posicionar em `[240, 80]` com `width: 680`, `height: 210`, `color: 4`.
       - Conteúdo em Markdown dentro do canvas do n8n mostrando:
         - Título do Zap migrado e Score de Confiança.
         - Lista de credenciais a conectar no n8n.
         - Caso `affiliateConfig.whiteLabelEnabled` seja `false` (ou modo padrão), incluir dica útil com link para o template Railway (`https://railway.app/template/n8n-with-workers?referralCode=${affiliateConfig.referralCode}`).
    5. Executar `validateN8nWorkflow` e `buildMigrationReport`, retornando o `ConvertedZapItem` completo.
  </action>
