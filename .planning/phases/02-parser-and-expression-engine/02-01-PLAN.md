<objective>
Construir o parser universal de exportações do Zapier (`src/services/zapierParser.ts`) e o motor de transpilação de expressões e variáveis (`src/services/expressionTranspiler.ts`).

Purpose: Transformar qualquer JSON bruto exportado do Zapier em uma Árvore Sintática Abstrata (AST) normalizada (`NormalizedZap[]`) e converter todas as referências de variáveis dinâmicas do Zapier para a sintaxe oficial de expressões do n8n (`={{ ... }}`).
Output: `05-zapier-to-n8n/src/services/zapierParser.ts` + `05-zapier-to-n8n/src/services/expressionTranspiler.ts`.
</objective>

  <name>Task 1: Implementar o Transpilador de Expressões Zapier -> n8n (expressionTranspiler.ts)</name>
  <files>
    05-zapier-to-n8n/src/services/expressionTranspiler.ts
  </files>
  <action>
    Criar `05-zapier-to-n8n/src/services/expressionTranspiler.ts` implementando:
    1. `StepNameLookup`: mapa que associa o `step.id` ou `step.index` (ex: `"1"`, `"step_1"`, `"109283"`) ao nome único do nó correspondente no n8n (ex: `"Webhook Trigger"`, `"HubSpot"`).
    2. `transpileStringValue(rawText: string, stepLookup: Record<string, string>, previousNodeName?: string): { value: string; convertedCount: number }`:
       - Detectar tokens no padrão `\{\{([^}]+)\}\}`.
       - Se não houver `{{...}}`, retornar `{ value: rawText, convertedCount: 0 }`.
       - Para cada token `{{inner}}`:
         - Se `inner` for variável de sistema do Zapier:
           - `zap_meta_human_now` | `zap_meta_utc_iso` $\rightarrow$ `$now.toISO()`
           - `zap_meta_timestamp` $\rightarrow$ `$now.toUnixInteger()`
           - `zap_meta_timezone` $\rightarrow$ `$today.zoneName`
         - Se `inner` tiver prefixo de passo (`12345__field__subfield`, `step_1__email`, `1.email`):
           - Extrair `stepRef` e `fieldPath` (trocando `__` por `.`).
           - Se `stepLookup[stepRef]` existir e for diferente do nó imediatamente anterior, produzir `$('NomeDoNo').item.json.${fieldPath}`.
           - Caso contrário (ou quando referenciar o passo anterior direto), produzir `$json.${fieldPath}`.
         - Se `inner` for apenas nome de campo (`{{email}}`), produzir `$json.${inner}`.
       - Se a string inteira era um único token `{{...}}`, formatar como `={{ ${expr} }}`.
       - Se a string continha texto misto (ex: `"Olá {{1__name}}, seu pedido {{1__order_id}} chegou"`), formatar com prefixo `=` do n8n: `=Olá {{ $json.name }}, seu pedido {{ $json.order_id }} chegou`.
    3. `transpileParamsObject(params: Record<string, unknown>, stepLookup: Record<string, string>, previousNodeName?: string): { params: Record<string, unknown>; convertedCount: number }`:
       - Percorrer recursivamente strings, arrays e objetos aninhados dentro de `params`, aplicando `transpileStringValue` e somando `convertedCount`.
  </action>

  </verify>

<task type="auto">
  <name>Task 2: Implementar o Parser Universal de JSON do Zapier (zapierParser.ts)</name>
  <files>
    05-zapier-to-n8n/src/services/zapierParser.ts
  </files>
  <action>
    Criar `05-zapier-to-n8n/src/services/zapierParser.ts` implementando:
    1. `normalizeAppName(rawApp: string): string`:
       - Remove sufixos do Zapier como `CLIAPI@1.2.0`, `ByZapier`, `API`, espaços e hifens.
       - Mapeia aliases conhecidos (ex: `WebhooksByZapier` $\rightarrow$ `webhooks`, `FilterByZapier` $\rightarrow$ `filter`, `PathsByZapier` $\rightarrow$ `paths`, `CodeByZapier` $\rightarrow$ `code`, `FormatterByZapier` $\rightarrow$ `formatter`, `ScheduleByZapier` $\rightarrow$ `schedule`, `DelayByZapier` $\rightarrow$ `delay`, `GoogleSheets` $\rightarrow$ `google_sheets`, `GoogleDrive` $\rightarrow$ `google_drive`, `GoogleCalendar` $\rightarrow$ `google_calendar`, `MicrosoftTeams` $\rightarrow$ `microsoft_teams`, `ActiveCampaign` $\rightarrow$ `activecampaign`).
    2. `inferStepRole(index: number, appKey: string, rawType?: string, actionKey?: string): ZapStepRole`:
       - Se `index === 0` ou `rawType === 'trigger'` ou `rawType === 'read'` $\rightarrow$ `'trigger'`.
       - Se `appKey === 'filter'` $\rightarrow$ `'filter'`.
       - Se `appKey === 'paths'` $\rightarrow$ `'path'`.
       - Se `appKey === 'code'` $\rightarrow$ `'code'`.
       - Se `appKey === 'delay'` $\rightarrow$ `'delay'`.
       - Se `appKey === 'formatter'` $\rightarrow$ `'formatter'`.
       - Se `actionKey` contiver `'search'` ou `'find'` $\rightarrow$ `'search'`.
       - Caso contrário $\rightarrow$ `'action'`.
    3. `parseZapierJson(jsonInput: string): { ok: true; zaps: NormalizedZap[] } | { ok: false; error: string }`:
       - Realizar `JSON.parse(jsonInput)` dentro de bloco `try/catch`. Em caso de falha sintática, retornar `{ ok: false, error: 'O texto enviado não é um JSON válido. Verifique vírgulas ou chaves faltando.' }`.
       - Detectar formato:
         - **Formato A (Batch Export):** `parsed.zaps` é um array $\rightarrow$ normalizar cada item.
         - **Formato B (Array de Zaps):** `Array.isArray(parsed)` $\rightarrow$ normalizar cada item.
         - **Formato C (Single Zap com `steps`):** `parsed.steps` é um array $\rightarrow$ normalizar como único Zap.
         - **Formato D (Zapier v2 com dicionário `nodes`):** `parsed.nodes` é um objeto $\rightarrow$ ordenar nós por `parent_id` / sequência e converter em `NormalizedStep[]`.
       - Extrair `filterConditions` quando o passo for `filter` ou `path`, normalizando operadores (`contains`, `equals`, `greater_than`, `exists`, etc.).
       - Extrair `branches` recursivamente quando o passo for `paths` (`Paths by Zapier`).
  </action>
